Verification / evidence of behavior

Test the boundaries,
not just the happy path.

01

Traceable sources

Document-hash checks and exact citation-span validation reject altered evidence.

02

Independent decisions

Report approval, candidate acceptance and knowledge promotion remain separate.

03

Controlled authority

ACL checks, blocked conflict publication and exact-draft domain-lead approval.

04

Reproducible outputs

Three skills, shared orchestration, frozen snapshots and immutability checks.

What the tested demo shows

A complete P2P scenario with synthetic evidence, repeatable mock generation, an end-to-end FastAPI workflow and a transport-level test of the live adapter.

The run instructions include the current local test count.

What it does not yet establish

Production authentication or tenant administration. General OCR, semantic-contradiction or claim-entailment guarantees. Authoritative S/4HANA recommendations. A production live-provider evaluation.

The synthetic fit-gap reference is only a comparison scenario.

Appendix A / Accountability chain

Every transition has an actor
and a deliberate limit.

GateAccountable roleWhat changes and what does not
Evidence captureSystem + authorized evidence readerStores immutable text and source spans. Conflicting evidence remains reviewable.
Draft generationConsultant via skill contractAuthorized snapshot → atomic claims → exact spans
Faithful-report reviewConsultant / domain leadRecord may accurately contain an unresolved issue. No candidate promotion.
Conflict flaggingConsultantCandidate becomes Conflicted. Baseline stays authoritative. Dependency reviews open.
WS-05 acceptanceDomain leadIntroduces written clarification and accepts scoped candidate before promotion.
Knowledge promotionDomain lead, independent actionv2 supersedes v1 for FR01. Both source versions stay bound to v2 provenance.
PublicationDomain lead, per deliverableApproves this scoped change for this exact draft. No conflict or unknown claims.
Operational safety ≠ general semantic truth. Evaluate both deliberately.
