01 / The Problem

Most AI tools write text.
Consultants must govern decisions.

01

Information Overload

30 workshops across 26 weeks produce huge volumes of meeting notes, process lists, and technical documents scattered across teams.

02

Repetitive Drafting & Drift

Consultants spend hours formatting reports instead of advising. Structure and thoroughness vary significantly from one author to another.

03

Hidden Contradictions

When Workshop 4 states €50,000 after Workshop 1 approved €25,000, standard AI tools either hallucinate or silently overwrite the baseline.

Core Principle: We do not build one tool per deliverable. We build one shared engine and plug in one skill per deliverable type.

Why FastAPI + Pydantic?

Minimal Python API server enforcing strict JSON output contracts on every skill and role-based checks on every route.

Why SQLite + FTS5 (No Heavy Vector DB)?

Single-file database handling relational knowledge versions, full-text passage retrieval, and immutable audit triggers with zero setup.

Why Mock Mode + Live Mistral?

Deterministic fixtures keep the interview demo fast and offline-safe; switching to Live Mistral requires only an API key, never a fallback.
